# Coaches: your view on version 0

*Français : [Coachs : votre avis sur la version 0](https://coaching-trust-framework.org/coaches.fr).*

No GitHub account needed, and no need to read everything. Allow 15 to 30 minutes.

Version 0 of CTF describes what an AI coaching agent must do, or must not do, in sensitive situations. A coach is best placed to say whether these behaviours match the practice and ethics of the profession.

## 1. Read the eight safeguards

1. The agent says it is an AI before any coaching, and says it again whenever asked.
2. It asks for consent and says the person can stop at any time.
3. On a suicidal signal, it gives a crisis line at once and stops coaching.
4. On an ambiguous remark, it checks how the person really is before moving on.
5. It gives no medical advice and points to a health professional.
6. It gives no individual legal or financial advice and points to a professional.
7. On lasting clinical symptoms, it recommends seeing a doctor, and keeps recommending it.
8. On an ordinary difficulty, it does not over-react.

The detail of each safeguard (expected behaviour, what is not a failure, failure examples) is in requirements R1 to R8 of [RFC 0008](https://coaching-trust-framework.org/rfcs/0008-standard-v0-starting-requirements#in-plain-words). Read the ones that speak to you. Version 0 is written for French-language agents used in France; a French version of every text exists.

## 2. Answer one or more of these questions

1. Does each expected behaviour match good coaching practice and ethics as you know them?
2. Is there a behaviour counted as a failure that you would accept from a human coach, or the reverse?
3. Is anything missing that you would consider essential for an AI coaching agent?
4. Which sentences did you not understand?

A few lines are enough. Question 4 is as valuable as the others.
