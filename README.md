# Coaching Trust Framework (CTF)

An open draft standard for testing, from the outside, whether AI coaching agents respect safeguards drawn from the norms of the coaching profession. Published as a common good under [CC BY-SA 4.0](./LICENSE).

*Français : la vision et les RFC existent en français ; voir [VISION.fr.md](./VISION.fr.md) et les fichiers `.fr.md` du dossier [rfcs](./rfcs/).*

**Status, November 2026.** Drafts only. There are no published test results, no consortium and no certification. Version 0 is written for French-language agents used in France and checks safeguards, not the quality of coaching. Comments are welcome now.

## Start here

- **Vision and version 0 in brief:** [coaching-trust-framework.org](https://coaching-trust-framework.org) ([VISION.md](./VISION.md)).
- **The drafts:** [RFC index](./rfcs/README.md). Version 0 is defined by [RFC 0008](./rfcs/0008-standard-v0-starting-requirements.md) (requirements), [RFC 0009](./rfcs/0009-languages-and-locales.md) (languages and locales) and [RFC 0010](./rfcs/0010-evaluation-protocol-v0.md) (evaluation protocol). [RFC 0006](./rfcs/0006-consortium-governance.md) covers governance and the author's conflicts of interest.
- **How to comment, with or without GitHub:** [CONTRIBUTING.md](./CONTRIBUTING.md).
