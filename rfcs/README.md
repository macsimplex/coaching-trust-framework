# Requests for Comments (RFCs)

This folder holds proposals to change the Coaching Trust Framework (CTF) standard. Each change goes through the same steps: proposal, public comment period, decision, new version of the standard.

Start a new RFC from [rfc-template.md](./rfc-template.md).

These RFCs and the template are restored verbatim from commit `9fff7de`, from before the repository was reset to its homepage and vision. RFCs 0006 (consortium governance) and 0007 (removal of self-declaration) are not restored yet; they remain on the `archive-v1` branch.

Some links in these files point to documents that the reset removed: `validation/methodology.md`, `CONTRIBUTING.md`, `GOVERNANCE.md` and `EXPLAINER.md`. They can still be read at commit `9fff7de`. Until those documents are rewritten:

- the comment periods stated in these RFCs (2026-11-09 to 2026-12-09) are kept as written.
