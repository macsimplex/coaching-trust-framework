# CTF Adopters

This file lists platforms, organizations and independent practitioners who implement the Coaching Trust Framework in their own AI coaching practice.

Inclusion in this list reflects the adopter's own self-declaration of conformance to CTF, following the procedure described in [`certification-scheme/self-declaration.md`](./certification-scheme/self-declaration.md). Inclusion is not a certification by the CTF project itself; it is the public face of the adopter's commitment.

If you are an adopter, please add yourself by submitting a pull request to this file.

## How to add yourself

1. Submit a pull request adding a new entry to the appropriate section of this file.
2. Include: platform name, type of activity, CTF version implemented, adaptation followed (generic or specific federation adaptation), link to your self-declaration document or page, and any relevant notes.
3. By submitting the pull request, you confirm that your platform genuinely implements CTF as documented in [`certification-scheme/self-declaration.md`](./certification-scheme/self-declaration.md).
4. The caretaker merges the pull request after a brief review for completeness. The accuracy of the self-declaration remains the adopter's responsibility.

If your circumstances change (you no longer implement CTF, you upgrade to a different adaptation, or you wish to be removed for any reason), simply submit a pull request to update or remove your entry.
